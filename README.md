# Deploy (Vercel, gratis)

1. Account maken op vercel.com
2. Deze map uploaden (drag & drop op vercel.com/new, of `vercel` command)
3. In Vercel → Settings → Environment Variables: voeg `ANTHROPIC_API_KEY` toe met jouw key
4. Redeploy

Klaar. De AI-knop werkt dan voor iedereen die de site bezoekt — niemand vult zelf een key in.
